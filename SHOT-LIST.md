# Shot list: The Lounge website

Every photo on the site has a day slot and a night slot, and so does the opening video. The site shows the day versions until sunset in Paradise Point, then fades to the night versions. Visitors can also flip between them with the Day / Night switch. Any night photo that doesn't exist yet falls back to a dimmed copy of the day photo.

To swap something in, save the new file under the same name and push it.

## How to shoot

- **Empty venue:** before opening for day shots, and after close or before service for night shots. Set the tables as if guests are about to sit down.
- **Stable camera:** use a tripod for photos. For video use a gimbal or tripod, and make one slow, smooth move per clip (a push-in, a slide or a slow pan), or hold completely still.
- **Clip length:** 8–12 seconds of clean footage per clip. The site trims and loops it.
- **Exposure:** lock exposure and white balance per clip so the light doesn't pulse.
- **Night:** dim the room lights to service level and switch on every table lamp and candle. Shoot after dark so the windows go black, and keep the sign lit.
- **Framing:** day and night shots of the same spot should be taken from the same position, same height, same lens. Then the fade between them looks like the lights changing, not a cut.
- **Size:** landscape, 4K if possible, highest quality. I'll compress everything for the web.
