# The Lounge website: Version A

A frozen copy of the site as it stood on 27 October 2026, kept for comparison with Version B.
Open `index.html` in a browser (the menu is `menu.html`). Nothing here is edited any more; the live site is the folder above.

What it is: a split opening screen (name on black, venue video beside it) that swaps from day to night after sunset
in Paradise Point; the terrace and the lit sign; the weekly specials from the What's On sheet with happy hour;
the bar after dark; OpenTable booking (restaurant 212261); address and hours. The menu page holds the full
July menu as dropdowns, without prices.
