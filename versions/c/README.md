# The Lounge website: Version C, Deco Esplanade

Art deco taken from the venue itself: the arch of the three lit back-bar shelves frames the opening video and the three photos below it, and two gold lines rise around the arch as the page opens. Sign black, bottle green and the sign's neon gold; Limelight for headlines, Karla for text. Current venue photos stand in until the reshoot. The menu page uses the shared menu data in `tools/menu`.
